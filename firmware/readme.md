## 8-Key Macropad Firmware

This directory is used to place the firmware files for the **8-Key Macropad**.

> **Note:** Only **V2 versions** of the 8-Key Macropad need to download the firmware from here.

### How to Use

**Step 1:** Download both `mc-08.bin` and `mc-08.json`, then copy them to the **root directory** of the device’s USB drive.

**Step 2:** Restart the keyboard by disconnecting and reconnecting the power.
