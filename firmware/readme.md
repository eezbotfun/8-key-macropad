## 8-Key Macropad Firmware

This directory is used to place the firmware files for the **8-Key Macropad**.

> **Note:** Only **V2 versions** of the 8-Key Macropad need to download the firmware from here.

## How to Use

**Step 1:** In the configuration software, select the Macropad you want to upgrade from the device list, then select **“Upgrade Firmware”** from the right-click menu.
####
<img width="2064" height="1167" alt="upgrade-fw" src="https://github.com/user-attachments/assets/22dbdf01-0ac7-424f-999e-b70cf21429e9" />

##

**Step 2:** Download both mc-08.bin and mc-08.json, then copy them to the root directory of the device’s USB drive.

##

**Step 3:** Click "Yes, Files Copied" button.
